# Mobimix — Access Guide

Automatic generation of data-quality analysis reports for urban mobility data.

---

## 1. What it does

You upload an Excel file describing **types of mobility data** (GPS traces, traffic
counting loops, ticketing, cameras...). For each type, the tool automatically produces
a **PDF analysis report** containing:

- the realistic **quality issues** these data may present,
- **detection algorithms** with their mathematical formulation and Python implementation,
- a **synthetic dataset** with injected anomalies to test them,
- a comparative summary.

Everything is generated by a language model hosted **on our own servers**: no data
leaves the infrastructure.

---

## 2. Prerequisites

SSH access to `dgxspark2.joyria.net` (username + key). If you do not have it, request
it before connecting.

---

## 3. Connecting — 3 steps

### Step 1: open the tunnel

In a terminal (**PowerShell** on Windows, **Terminal** on Mac/Linux):

```
ssh -i <path_to_your_key> -L 8501:localhost:8501 <your_login>@dgxspark2.joyria.net
```

Concrete example:

```
ssh -i C:\Users\jsmith\.ssh\my_key -L 8501:localhost:8501 jsmith@dgxspark2.joyria.net
```

> ⚠️ **Keep this window open** while using the application. It maintains the
> connection.

### Step 2: open your browser

Go to: **http://localhost:8501**

### Step 3: log in

Enter the **access password** (provided separately) and **your name or email** — the
latter is only used to track who submitted which request.

**To leave**: close the browser tab, then type `exit` in the terminal.

---

## 4. Using the application

The interface has three tabs.

### 📤 New request

Upload your Excel catalogue. The file is **validated before any processing**:
recognised columns, empty rows, duplicates. You get a preview and a duration estimate,
then confirm.

**Expected format** — one row per data type:

| Column | Required | Accepted names |
|---|---|---|
| Name | **yes** | `nom`, `name`, `type`, `type de donnée`, `libellé` |
| Description | no | `description`, `desc`, `détails` |
| Characteristics | no | `caractéristiques`, `spécifications`, `specs` |
| Sources | no | `sources`, `capteurs` |

The more descriptive columns you fill in, the more relevant the reports.

**Limits**: 5 rows maximum per file, 5 MB maximum.

### ⏳ My jobs

Tracking of your requests: queued, running, done, error. You can close the page and
come back later — **processing continues on the server**.

### 📄 Reports

List of all available PDF reports, with a search field. One click to download.

---

## 5. Before you start

**Processing is slow.** Allow roughly **40 minutes per data type**. A 5-row file
therefore takes over 3 hours. This is not a bug: the model generates several thousand
lines of content per report, on a shared GPU.

**One request at a time.** The server processes requests serially so as not to saturate
the GPU. If someone else launches a job, wait until it finishes.

**Current report limitation.** Structure, analysis and code are complete, but the
**numerical results tables** (F1-score, precision, recall) are still empty — a fix is
in progress. Reports remain usable for their methodological content.

## 6. Common problems

| Symptom | Cause | Fix |
|---|---|---|
| `Connection refused` in the browser | tunnel closed | rerun the SSH command |
| `bind: Address already in use` | port 8501 already taken locally | use `-L 8600:localhost:8501` and go to `http://localhost:8600` |
| `Permission denied (publickey)` | wrong SSH key | check the key path and your login |
| Page will not load | application may be stopped | contact Youness |
| "A job is already running" | someone is using the GPU | try again later |
| File rejected | too many rows, or missing name column | read the error message, it states the problem |
